Two Different "Claudes" on Windows — Which One Do You Want? Windows上的两种"Claude"——你想要哪一种？

Before installing anything, it helps to know there are two different ways to get Claude onto a Windows PC, and they do different jobs: 在安装任何东西之前，先了解一下在Windows电脑上获取Claude有两种不同的方式，它们的用途也不同：

💡 Claude Desktop App vs. Claude Code 💡 Claude桌面版 与 Claude Code的区别
  • Claude Desktop (the app) — a normal Windows program you download and click to install, just like installing any app. This is what most people want: a chat window on your desktop for asking questions, writing, and using AI in daily life. This is what this guide covers.Claude桌面版（应用程序）——一个普通的Windows程序，下载后点一下就能安装，就像安装任何应用一样。这是大多数人想要的：桌面上有一个聊天窗口，用来提问、写作、在日常生活中使用AI。本指南讲的就是这个。
  • Claude Code — a more technical, terminal-based tool for people who want Claude to directly edit files and run commands on their computer (I covered installing that one already, in AIT04). You don't need this just to chat with Claude.Claude Code——一个更技术性的、基于终端的工具，适合想让Claude直接编辑电脑上的文件、运行命令的人（我已经在AIT04里介绍过它的安装方法了）。如果你只是想和Claude聊天，不需要这个。

I nearly installed the wrong one the first time. If all you want is a chat window on your desktop, you want the app — not the terminal tool.我第一次差点装错了那个。如果你只是想在桌面上有个聊天窗口，你要的是应用程序——不是终端工具。

Step-by-Step: Installing the Claude App on Windows 一步步：在Windows上安装Claude应用

This is the easy path — no terminal, no typing commands. Just downloading and clicking, the same way you'd install any program. 这是简单的路——不用终端，不用输命令。就是下载、点击，和安装任何普通程序一样。

Go to claude.ai on Your Windows PC在你的Windows电脑上打开claude.ai

Open your web browser (Edge, Chrome, whichever you normally use) and go to claude.ai. If you don't have an Anthropic account yet, click "Sign Up" and create one with your email — it's free to start.打开你的浏览器（Edge、Chrome，你平时用哪个都行），访问claude.ai。如果你还没有Anthropic账户，点击"Sign Up"用你的邮箱注册一个——免费开始使用。

Find the Download Page找到下载页面

Once signed in, look for a "Download App" link — it's usually in the sidebar menu or under your account settings. This takes you to a page offering downloads for Windows, Mac, iOS and Android. Click the Windows download button.登录后，找到"Download App"（下载应用）的链接——通常在侧边栏菜单里，或者在账户设置下面。点进去后会看到一个页面，提供Windows、Mac、iOS和Android版本的下载。点击Windows下载按钮。

Run the Installer File运行安装文件

A file ending in .exe will download to your Downloads folder. Double-click it to open it. Windows may show a blue "Windows protected your PC" warning — this is normal for new apps. Click "More info", then "Run anyway".一个以.exe结尾的文件会下载到你的"下载"文件夹。双击打开它。Windows可能会弹出一个蓝色的"Windows已保护你的电脑"警告——这对新应用来说很正常。点击"更多信息"，然后点"仍要运行"。

Let It Install Automatically让它自动安装

The installer copies the files onto your computer and finishes on its own within a minute or so — there's usually nothing to click through, no "Next, Next, Finish" wizard. When it's done, the Claude app opens by itself.安装程序会把文件复制到你的电脑上，大约一分钟左右自动完成——通常不需要点什么"下一步、下一步、完成"的向导。完成后，Claude应用会自动打开。

Sign In and Start Chatting登录并开始聊天

Sign in with the same account you created at claude.ai. You'll land on a familiar chat screen — the same one you'd see in a browser, except now it lives as its own app on your desktop and Start menu, ready with one click.用你在claude.ai注册的同一个账户登录。你会看到一个熟悉的聊天界面——和浏览器里看到的一样，只是现在它作为一个独立的应用，出现在你的桌面和开始菜单里，一键就能打开。

🎉

That's it. No terminal, no API key to paste in, no command to memorise. Five clicks and you have Claude sitting on your Windows desktop, ready whenever you are. 就这样。 不用终端，不用粘贴API密钥，不用记什么命令。五次点击，Claude就安安稳稳地待在你的Windows桌面上，随时等你使用。

Common Problems and How to Fix Them 常见问题及解决方法

🔧 Troubleshooting Guide 🔧 故障排除指南
  • "Windows protected your PC" won't go away — Click directly on the words "More info" (not the big "Don't run" button) and a "Run anyway" button will appear underneath. "Windows已保护你的电脑"一直不消失——直接点击"更多信息"这几个字（不要点大大的"不要运行"按钮），下面就会出现"仍要运行"的按钮。
  • The download button only shows Mac/iOS — Make sure you're browsing on the Windows PC itself, not viewing the page on your phone. The site detects your device and may hide the wrong options. 下载按钮只显示Mac/iOS版本——确认你是在Windows电脑本身上浏览，而不是在手机上查看这个页面。网站会检测你的设备，可能会隐藏不适用的选项。
  • App opens but asks to sign in again and again — Close the app fully from the Windows system tray (bottom-right corner, not just the X button), then reopen it and sign in once more. 应用打开后反复要求重新登录——从Windows系统托盘（右下角，不只是点X关闭按钮）彻底关闭应用，然后重新打开再登录一次。
  • Company or work laptop blocks the install — Some workplace IT policies block new software installs entirely. If that happens, claude.ai still works perfectly in a normal browser tab — you lose nothing except the separate desktop icon. 公司或工作电脑禁止安装——有些公司的IT政策会完全禁止安装新软件。如果遇到这种情况，claude.ai在普通浏览器标签页里依然能完美使用——你只是少了一个独立的桌面图标，其他功能都不受影响。

The Bonus Lesson — Drawing 3D Diagrams with AI 额外收获——用AI画3D图

The part of the video I didn't expect was the second half — showing how to get Claude to actually draw 3D diagrams, not just describe them in words. This turned out to be one of the most useful tricks I've picked up all year, especially for explaining ideas that are hard to picture from flat text alone. 视频里我没想到的是后半部分——展示了如何让Claude真正画出3D图，而不只是用文字描述。这成了我今年学到的最有用的技巧之一，尤其是在解释那些光靠文字很难想象的概念时。

The trick is simple: instead of asking for a "picture," you ask Claude to build the diagram as a small piece of interactive code — the same kind of technology that makes video games render 3D shapes in a browser. Claude writes it, and you see a real, rotatable 3D object appear right in the chat window. 窍门很简单：不要要求"一张图片"，而是让Claude把这张图建造出来，做成一小段可交互的代码——就是让视频游戏能在浏览器里渲染3D图形的那种技术。Claude把代码写出来，你就能在聊天窗口里看到一个真实的、可以旋转的3D物体出现。

💬 Example Prompts That Produce 3D Diagrams 💬 能画出3D图的示例提示词
  • "Draw an interactive 3D diagram of a house with labelled rooms, so I can rotate it and look inside.""画一个带标注房间的可交互3D房屋图，让我可以旋转并查看内部。"
  • "Create a 3D isometric diagram showing how a company's departments report to each other.""创建一个3D等距图，显示一家公司各部门之间的汇报关系。"
  • "Show me a rotating 3D model of a wind turbine with the main parts labelled.""给我看一个旋转的3D风力发电机模型，主要部件都标注出来。"
  • "Build a 3D diagram of my investment portfolio, with each holding as a block sized by its value.""建一个我投资组合的3D图，每个持仓用一个方块表示，大小按价值决定。"

I asked for a 3D diagram of how my website's pages link to each other. Watching it build itself, block by block, in a window I could spin around with my mouse — that felt like magic, not typing.我请它画一个我网站页面之间链接关系的3D图。看着它一块一块地自己搭建起来，在一个我能用鼠标转动查看的窗口里——那感觉像魔法，不像打字。

Describe what you want in plain words first.先用简单的话描述你想要什么。

Say what the diagram is of, and what the different parts/labels should be. You don't need to know anything about 3D graphics or code — Claude handles that part entirely.说明这张图是关于什么的，各个部分/标签应该是什么。你完全不需要懂3D图形或代码——这部分完全由Claude来处理。

Ask for "interactive" and "rotatable."要求"可交互"和"可旋转"。

Using those two words nudges Claude towards building a real 3D scene you can drag around with your mouse, rather than a flat, static picture.用上这两个词能促使Claude搭建一个真正的3D场景，让你能用鼠标拖动查看，而不是一张平面的静态图片。

Refine it like a conversation.像聊天一样不断调整。

If a colour is wrong, a label is missing, or a part is out of proportion, just say so in plain English — "make the roof red" or "the labels are too small to read" — and Claude rebuilds it on the spot.如果颜色不对、少了标签、或者某个部分比例不对，直接用简单的话说出来——"把屋顶改成红色"或者"标签太小看不清"——Claude会当场重新搭建。

⚠️

Not every response becomes 3D automatically. If Claude replies with only a text description or a flat picture, ask directly: "Can you build this as an interactive 3D diagram instead?" That one sentence usually does the trick. 不是每次回复都会自动变成3D。 如果Claude只回了文字描述或一张平面图片，直接问它："能不能改成一个可交互的3D图？"这一句话通常就能解决。
