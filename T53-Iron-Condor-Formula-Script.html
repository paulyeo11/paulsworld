Overview概述

User enters a ticker code. The tool looks up its current share price and, based on whether that price is above or below an adjustable threshold, applies one of two sets of Gap/Time multipliers to compute all 4 Iron Condor strikes.用户输入股票代码。工具会查询其当前股价，并根据该股价是否高于或低于可调整的门槛，套用两组间距(Gap)/倍数(Time)参数中的一组，计算出铁鹰策略的全部4条腿行权价。

Step-by-Step Logic逐步逻辑

Step 1: User enters the share ticker code. Step 2: Example — user selects QQQ. Step 3: Share Price (QQQ) displays the current share price, e.g. $600. Step 4: Since share price > 300 → go to Case (1). Step 5: Example — user enters NVDA. Assume NVDA current share price = $200. Step 6: Share Price (NVDA) displays $200. Since share price < 300 → go to Case (2).步骤1：用户输入股票代码。 步骤2：例如用户选择 QQQ。 步骤3：股价（QQQ）显示当前股价，如 $600。 步骤4：由于股价 > 300 → 进入案例(1)。 步骤5：例如用户输入 NVDA。 假设NVDA当前股价 = $200。 步骤6：股价（NVDA）显示 $200。 由于股价 < 300 → 进入案例(2)。
Case (1): Share Price (A) > Threshold ($300)案例(1)：股价 (A) > 门槛 ($300)

Threshold ($300) is a dynamic variable — user can adjust it. Example: QQQ, share price $600.门槛($300)为动态变量，用户可自行调整。示例：QQQ，股价 $600。

Gap (G) = $10 Time (T) = 0.9 ← Selling Put multiplier Time1(T1) = 1.1 ← Selling Call multiplier (A) Selling Put = Share Price × Time = $600 × 0.9 = $540.00 (B) Buying Put = Selling Put + Gap = $540 + $10 = $550.00 (C) Selling Call = Share Price × Time1 = $600 × 1.1 = $660.00 (D) Buying Call = Selling Call + Gap = $660 + $10 = $670.00Gap (G) = $10 Time (T) = 0.9 ← 卖出认沽倍数 Time1(T1) = 1.1 ← 卖出认购倍数 (A) 卖出认沽 = 股价 × Time = $600 × 0.9 = $540.00 (B) 买入认沽 = 卖出认沽 + Gap = $540 + $10 = $550.00 (C) 卖出认购 = 股价 × Time1 = $600 × 1.1 = $660.00 (D) 买入认购 = 卖出认购 + Gap = $660 + $10 = $670.00
