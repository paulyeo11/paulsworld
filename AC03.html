AC03: Connecting AI to My Company's ERP Database

AC03：把AI接上我公司的ERP数据库

Using an MCP connection and an API key, I linked AI straight into our field tech company's ERP system — and discovered a completely different way to see the business.

用一个MCP连接和一个API密钥，我把AI直接接上了我们field tech公司的ERP系统——从此用一种完全不同的方式看懂了这门生意。

Yesterday I did something I had never tried before: I connected AI directly to our company's ERP database using MCP and an API key, and asked it to help me analyse our sales order and invoice data. What I found was a benefit far bigger than I expected — not just a faster way to pull numbers, but a completely different way to understand the business. 昨天我做了一件以前从未尝试过的事：我用MCP和一个API密钥，把AI直接连接到我们公司的ERP数据库，请它帮我分析销售订单和发票数据。结果发现的好处，比我预期的大得多——这不只是更快地把数字拉出来，而是一种完全不同的理解生意的方式。

🛠️ What I Did🛠️ 我做了什么

Our field tech company runs on an ERP system to manage sales orders, invoices, and customer records. I set up an MCP connection with an API key to let AI reach into that database directly. As a first test, I kept it simple — I asked AI to update and read our sales order data, meaning all of our invoices.

我们的field tech公司用一套ERP系统来管理销售订单、发票和客户记录。我用一个API密钥设置了MCP连接，让AI能够直接读取那个数据库。作为第一次测试，我保持简单——我请AI更新并读取我们的销售订单数据，也就是我们所有的发票。

· · ·

✅ Benefit 1 & 2 — Easy to Connect, Fast to Update✅ 好处一和二——连接容易，更新超快

  • Very easy to connect. I was able to link AI to the ERP database without much issue at all — no complicated setup, no wrestling with the system. 连接非常容易。我几乎没遇到什么问题就把AI连上了ERP数据库——不需要复杂的设置，也不用跟系统搏斗。
  • Raw data updates very fast. Pulling and refreshing the sales order / invoice data through AI was much quicker than I expected. 原始数据更新速度非常快。通过AI拉取和刷新销售订单/发票数据，比我预期的要快得多。
· · ·

📈 Benefit 3 — AI Data Visualization is a Different World📈 好处三——AI数据可视化是完全不同的世界

When I got to the reporting part, I realised something important: doing data visualization with AI is a lot different from the past, when I used QlikView and Power BI. With those tools, I had to build the report myself. With AI, it analyses my data and gives me feedback immediately — so I can take action based on that feedback right away.

到了做报表这一步时，我意识到一件重要的事：用AI做数据可视化，和过去用QlikView、Power BI的时候非常不一样。用那些工具，报表得靠我自己去做。用AI，它会分析我的数据，立刻给我反馈——这样我就能马上根据反馈采取行动。

The old tools gave me a chart. AI gives me an answer — and tells me what to do about it. 旧工具给我的是一张图表。AI给我的是一个答案——还会告诉我该怎么处理。

👑 Example: Finding My Important Customers (80/20 Rule)👑 例子：找出我的重要客户（80/20法则）

I can simply ask AI to list out which are my important customers. In business, we need to focus on our important customers — the 80/20 rule. We focus 80% of our time on the 20% of customers who matter most, and that's how we achieve maximum results.

我可以直接请AI列出哪些是我的重要客户。做生意，我们需要聚焦在重要客户身上——也就是80/20法则。我们把80%的时间，投入在最重要的那20%客户身上，这样才能取得最大的成果。

💰 Example: Pinpointing Profit Problems💰 例子：精准找出利润问题

AI can also help me analyse gross profit or net profit, so that from the report I'm able to straightaway pinpoint which customers have low profit margins, why the margin is so low, and how to prevent this from happening — so the company can achieve maximum profit.

AI也能帮我分析毛利或净利，让我从报表中立刻精准地找出哪些客户的利润率偏低、为什么这么低，以及该如何预防这种情况再次发生——从而让公司获得最大利润。

There are many, many more reports I can ask AI to provide — and it is very easy to use.

还有非常非常多的报表可以请AI来提供——而且使用起来非常简单。

· · ·

💬 As Easy as Just Talking💬 就像聊天一样简单

What I need to do is simply talk to AI. Like right now, writing this very article — I just told AI what happened, and it took about five minutes to generate the article for me, so I can keep it as my achievement.

我需要做的，就是直接跟AI说话。就像现在写这篇文章一样——我只是告诉AI发生了什么事，它大约花了五分钟就帮我把文章写出来了，让我可以把这个记录下来，作为我的成就。

⚠️ The Downsides — It's Not Free⚠️ 也有缺点——这不是免费的

To be fair to myself, I should also record the cons, not just the benefits. There are three real disadvantages I've run into with this project.

公平地说，我也应该把缺点记录下来，而不是只写好处。这个项目让我遇到了三个真实的缺点。

  • 1. It costs money — and tokens run out. I'm on the Claude Code AI monthly subscription at S$30. The downside is I don't have unlimited tokens — I can only work about 1–2 hours a day depending on how fast I burn through them, then I need to rest around 4 hours before I can continue. I've since learned how to save tokens so I get more out of each session, but the limit is still there. 1. 要花钱——而且token会用完。我用的是Claude Code AI的月费订阅，S$30。缺点是token不是无限的——根据我用token的速度，每天大概只能工作1到2小时，之后要休息大约4小时才能继续。后来我学会了怎么省token，让每次能用得更久，但这个限制还是存在的。
  • 2. I also had to start paying for Vercel hosting. Every report lives on my website, so I need Vercel to host it — about $20 a month. I never used to pay for it. But after testing the free version for about 2 months, the only problem I hit was that Vercel stopped my deployments once I passed their daily limit (100 deployments a day), because I was deploying quite a lot. Today I decided it was worth paying for the subscription so that doesn't happen anymore. 2. Vercel网站托管也要开始付费。每一份报表都放在我的网站上，所以需要Vercel来托管——大概$20一个月。以前我从来不用付费。但用免费版测试了大概2个月后，我遇到的唯一问题是：一旦超过每天的部署上限（每天100次），Vercel就会停止我的部署，因为我部署得挺频繁的。今天我决定订阅付费版，值得，这样就不会再发生这个问题了。
  • 3. The initial setup was a bit difficult. I first had to install Claude Code on my PC. My habit is I don't like working directly on the desktop, so I run it remotely from my iPhone — which means my PC must always stay switched on with remote control active. If my PC ever has a power failure or hangs one day, I won't be able to run AI from my phone. It's not a small thing to set up. But whenever I hit a problem, I just ask AI itself to help me solve it. 3. 初期设置有点困难。我首先得在我的电脑上安装Claude Code。我的习惯是不喜欢直接在桌面上操作，所以我是用iPhone远程操作的——这意味着我的电脑必须一直开着，远程控制功能也要保持启用。万一哪天电脑突然断电或死机，我就没办法用手机远程运行AI了。这不是一件小事。但每次遇到问题，我就直接问AI，让它帮我解决。

📈 Why It's Still Worth It📈 为什么还是值得

Even with those costs, I find I benefit a lot — because now I'm able to trade options. I've learned how to trade the Iron Condor strategy, which used to be very complicated for me, and I know how to use AI to help me manage the trade — telling me which position is hitting its cutoff point so I know I must close it and lock in the profit.

即使有这些成本，我还是觉得受益很大——因为现在我能交易期权了。我学会了铁鹰策略（Iron Condor）的交易方式，这在以前对我来说非常复杂，而且我知道怎么用AI帮我管理交易——告诉我哪个仓位碰到了止损/止盈点，让我知道该平仓、锁定利润了。

📊 A Real Example — Still Learning📊 一个真实例子——还在学习中

Over the last two weeks I traded 4 Iron Condor positions. Because the market moved a lot, 3 of them had to be closed early: one position suddenly dropped a lot about 10 days ago and had to be closed within 3–4 days, QQQ's share price suddenly dropped and had to be closed, and NVDA's price also suddenly dropped. In each case I wasn't able to collect the full premium I would have in calmer market conditions. If the share price fluctuation had been smaller, like in normal times, I'd have been able to collect a lot more premium. I'm still learning.

过去两周我交易了4个铁鹰策略仓位。因为市场波动很大，其中3个必须提前平仓：一个仓位大约10天前突然大跌，必须在3到4天内平仓；QQQ的股价突然下跌，也必须平仓；NVDA的价格同样突然下跌。每一次我都无法收到像市场平稳时那样完整的权利金。如果股价波动像平常那样小一些，我本来可以多收不少权利金。我还在学习中。
